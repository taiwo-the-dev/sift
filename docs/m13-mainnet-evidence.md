- The earlier hosted Supabase project was reported as `paused` by the authenticated CLI
  on 2026-08-25. The M13 migration therefore could not be linked, dry-run, or
  applied at that time. The active project later accepted the M13 schema and
  bootstrap writes, as proven by the completed report above.
- Earlier recent-range public RPC reads passed, but the tested unauthenticated providers
  either reject historical state, cap `eth_getLogs` at very small ranges, or
  rate-limit the full deployment-to-head bootstrap. An archive-capable endpoint
  was later supplied and the resumable bootstrap reached its confirmed head.
